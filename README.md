
## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

我们要验证同一份源码在不同时间或不同目录下构建出的产物是否完全一致。请从零实现一个构建可复现性验证组件。仓库目前只有一个空的 Maven 工程（pom.xml 只声明 JUnit 5 与 AssertJ）。要求：1) 支持采集产物目录的快照：文件相对路径、大小与内容摘要；2) 支持两次采集结果对比，输出新增、删除与内容不同的文件清单；3) 支持忽略规则：时间戳文件、构建日志等易变文件可按路径或内容模式排除；4) 支持非确定性检测：多次采集同一构建产物时若自身就不一致，要能识别并报告是构建不确定而非对比逻辑问题；5) 支持归档信息比对：产物内嵌的构建时间、主机名等元数据差异要与真实内容差异分开报告；6) 支持结果判定：完全一致、仅元数据差异、存在内容差异三种结论及各自退出状态；7) 提供统计：文件数、一致文件数、差异文件数与被忽略文件数；8) 测试覆盖快照采集、差异分类、忽略规则、自身不确定性检测、元数据分离与判定结果；`mvn -q verify` 一条命令跑通。

## 提交要求

1. 在本仓库中完成提示词要求的全部内容。
2. `./mvnw -q verify` 必须通过。
3. 完成后在所属分支（A 或 B）上提交，产物快照的父提交必须是初始环境快照。
